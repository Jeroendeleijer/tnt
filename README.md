# Tech&Turn Distress Screen

A web page that diagnoses a company in distress: the situation, the next 90
days, how the company rates itself against what its accounts support, and what
to fix first.

It runs entirely in the visitor's browser. The Python engine is loaded through
Pyodide 0.29.5 from jsDelivr; nothing a visitor enters is sent anywhere.

This repository holds only the built page. It is generated by
`scripts/build_web.py` in the framework repository (v0.4.0) and should not
be edited by hand.
